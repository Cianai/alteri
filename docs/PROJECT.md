# AI Alignment Comparator - Project Context

## Overview

This project compares three approaches to AI alignment in mental health contexts:

1. **Microsoft HSI (Humanist Superintelligence)** - Domain containment, human-in-loop, interpretability
2. **Anthropic Constitutional AI** - Soul document hierarchy, brilliant friend model, anti-sycophancy
3. **Hybrid Approach** - Synthesising HSI containment with Constitutional AI character training

## Course Context

Academic project for **RELI E-1730: Mindfulness, AI, and Ethics** at Harvard Extension School.
